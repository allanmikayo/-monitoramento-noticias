Por que não é automático

O Smart exige sessão autenticada, e a API que o portal usa recusa requisição sem o header de autorização que só o app dele emite — testado abrindo o endpoint direto no navegador já logado. Um job do GitHub Actions bateria na mesma porta, como acontece com as notícias que vêm de sites abertos. Por isso a coleta roda onde a sessão existe: no seu navegador.

O caminho para tornar isso automático de verdade é uma credencial de serviço para o endpoint research/v1/reports, emitida pela tecnologia — o mesmo modelo do ANBIMA_CLIENT_ID que você já usa. Com ela, um workflow passa a rodar sozinho.

Sobre o token neste link: ele autoriza escrever no repositório. Não compartilhe o favorito nem esta página. Se vazar, troque COBERTURA_INGEST_TOKEN na Vercel e reinstale o botão.
